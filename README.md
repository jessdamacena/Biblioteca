# Sistema de Cadastro de Biblioteca

Aplicação de linha de comando em Python para gerenciar o acervo de uma biblioteca.
Projeto desenvolvido no curso de programação do ICMC/USP.

## Funcionalidades

- Cadastro de livros (título, autor, ano e disponibilidade)
- Listagem do acervo completo
- Busca por título ou autor
- Empréstimo e devolução de livros
- Persistência dos dados em arquivo JSON
- Contador de acervo (total, disponíveis e emprestados)
- Remoção de livros

## Como executar

Requisito: Python 3 instalado.

    python biblioteca.py

O arquivo `livros.json` é criado automaticamente no primeiro cadastro.

## Conceitos praticados

Funções, listas, dicionários, laços de repetição, condicionais, manipulação de arquivos e JSON.
